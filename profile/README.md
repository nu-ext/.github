# NuExt

**NuExt** stands for **New Extensions**: pragmatic .NET building blocks for real applications, focused on correctness, predictability, performance, and explicit design.

## Projects

- [NuExt.System](https://github.com/nu-ext/NuExt.System) — foundational utilities for async programming, threading, lifetime management, collections, I/O, and diagnostics.
- [NuExt.Minimal.Mvvm](https://github.com/nu-ext/NuExt.Minimal.Mvvm) — MVVM core with deterministic commands, asynchronous lifecycle, and hierarchical service resolution.
- [NuExt.Minimal.Mvvm.SourceGenerator](https://github.com/nu-ext/NuExt.Minimal.Mvvm.SourceGenerator) — compile-time boilerplate generation for `NuExt.Minimal.Mvvm`.
- [NuExt.Minimal.Mvvm.Wpf](https://github.com/nu-ext/NuExt.Minimal.Mvvm.Wpf) — WPF infrastructure for Views, dialogs, documents, windows, dispatchers, and deterministic cleanup.
- [NuExt.Minimal.Mvvm.MahApps.Metro](https://github.com/nu-ext/NuExt.Minimal.Mvvm.MahApps.Metro) — MahApps.Metro integration for dialogs and tabbed documents.
- [NuExt.Minimal.Behaviors.Wpf](https://github.com/nu-ext/NuExt.Minimal.Behaviors.Wpf) — reusable WPF behaviors and command interactivity.
- [NuExt.Presentation.Wpf](https://github.com/nu-ext/NuExt.Presentation.Wpf) — WPF presentation helpers, binding utilities, diagnostics, styles, and control extensions.
- [NuExt.System.Data](https://github.com/nu-ext/NuExt.System.Data) — lightweight data-access utilities and abstractions.
- [NuExt.System.Data.SQLite](https://github.com/nu-ext/NuExt.System.Data.SQLite) — SQLite integration and database context infrastructure.

## Packages
